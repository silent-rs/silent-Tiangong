# 图片生成提示词

## 基本描述
女孩在图书馆的窗户前，看向远方

## 详细场景描述
一位年轻女孩站在图书馆内，面向一扇明亮的窗户。她正凝视着窗外的远方，沉浸在思考或遐想中。

## 场景要素

### 主体人物
- **角色**: 年轻女孩
- **姿态**: 站立，侧身面向窗户
- **动作**: 凝视远方
- **表情**: 宁静、沉思
- **服装**: 休闲舒适的日常服装

### 环境设置
- **地点**: 图书馆内部
- **位置**: 靠近窗户的位置
- **周围**: 书架、书籍、阅读区域
- **窗户**: 大型落地窗或高窗

### 光线效果
- **主光源**: 窗外自然光（柔和的日光）
- **光线方向**: 从窗户照入，形成轮廓光
- **氛围**: 温暖、宁静、梦幻
- **阴影**: 柔和的阴影，增加立体感

## 艺术风格建议

### 可选风格
1. **写实风格**: 摄影般真实的光影效果
2. **插画风格**: 温暖柔和的色彩，略带梦幻
3. **油画风格**: 印象派风格，强调光影变化
4. **水彩风格**: 轻盈透明，富有诗意

### 推荐风格
**温暖的写实插画风格** - 结合真实的光影效果和柔和的艺术处理，营造宁静梦幻的氛围

## 色彩方案
- **主色调**: 温暖的米色、棕色（图书馆木质元素）
- **辅助色**: 柔和的蓝色、金色（窗外光线）
- **对比色**: 深棕色书架 vs 明亮的窗户光线

## 构图建议
- **视角**: 侧角或四分之三视角
- **焦点**: 女孩的侧脸轮廓和凝视的眼神
- **景深**: 前景清晰（女孩和窗户），背景略微虚化（书架）
- **空间**: 窗户在画面中占据重要位置，形成画框效果

## 情绪氛围
- **主要情绪**: 宁静、沉思、向往
- **氛围关键词**: 
  - 温暖 (warm)
  - 宁静 (peaceful)
  - 梦幻 (dreamy)
  - 怀旧 (nostalgic)
  - 知性 (intellectual)
