# 文档归档说明

本目录用于存放以下类型的历史文档：

- 已完成阶段的实施计划
- 迁移过程中的临时方案稿
- 已不作为当前基线的分析文档
- 仍有参考价值但不应继续作为主线依据的设计稿

归档原则：

- 当前产品基线、需求基线、RFC、正式接入文档保留在 `docs/`
- 历史方案、专题分析、验证清单迁入 `docs/archive/`
- 被代码或主文档引用的归档文档，需同步修正引用路径

当前主线文档应优先查看：

- `README.md`
- `PLAN.md`
- `TODO.md`
- `docs/requirements.md`
- `docs/desktop-agent-technical-architecture.md`
- `docs/architecture-gap-analysis.md`
- `docs/tiangong-core-integration.md`
- `docs/rfc/`
