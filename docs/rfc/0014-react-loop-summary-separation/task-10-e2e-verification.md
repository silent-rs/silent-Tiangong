# 10 - 端到端验收

## 目标

对 ReAct Loop 与总结阶段分离架构进行全面端到端验收，确保所有场景正常工作。

## 范围

- 全项目验证

## 依赖

- 前置任务：01, 02, 03, 04, 05, 06, 07, 08, 09
- 后续任务：无
- 可并行任务：无
- 阻塞说明：所有功能任务完成后才能进行

## 任务

### 编译与单元测试

- [ ] `cargo check` 全项目通过
- [ ] `cargo test -p tiangong-core` 通过
- [ ] `cargo clippy` 无新增 warning
- [ ] 前端 `npm run build` 通过

### 场景验证

- [ ] **场景 1：简单问答**
  - 发送"你好"
  - 预期：直接进入总结阶段，输出回复，不进入 ReAct Loop
  - 验证：无工具调用事件，有 `SummaryText` 事件

- [ ] **场景 2：单步工具调用**
  - 发送"列出当前目录文件"
  - 预期：进入 ReAct Loop 执行工具 → 进入总结阶段输出回复
  - 验证：有 `ReactText` 事件（工具过程），有 `SummaryText` 事件（最终回复）

- [ ] **场景 3：多步工具调用**
  - 发送"读取文件内容并总结"
  - 预期：多轮工具调用 → 总结阶段判断完成 → 输出回复
  - 验证：多轮 `ReactText`，最终一轮 `SummaryText`

- [ ] **场景 4：向用户提问**
  - 发送需要额外信息的请求（如"帮我连接数据库"）
  - 预期：LLM 在总结阶段向用户提问，正常结束
  - 验证：`SummaryText` 包含提问内容，无 `[NEED_MORE_WORK]`

- [ ] **场景 5：任务未完成重入 Loop**
  - 发送复杂任务，观察总结阶段是否正确判断未完成
  - 预期：总结输出 `[NEED_MORE_WORK]` → 重新进入 Loop → 再次总结完成
  - 验证：`PhaseChanged` 事件显示阶段切换

- [ ] **场景 6：外层循环超限**
  - 构造持续判定未完成的场景
  - 预期：超过 `MAX_OUTER_ITERATIONS` 后，`force_final_response` 输出最终回复
  - 验证：最终回复包含已完成和未完成的说明

- [ ] **场景 7：内层 Loop 超限**
  - 构造持续工具调用的场景
  - 预期：超过 `MAX_TOOL_ROUNDS` 后，进入总结阶段
  - 验证：总结阶段正常输出

- [ ] **场景 8：取消操作**
  - 在 ReAct Loop 中发送取消
  - 在总结阶段发送取消
  - 预期：立即停止，发送 `Error` 事件

- [ ] **场景 9：消息注入**
  - 在 ReAct Loop 中注入用户消息
  - 在总结阶段注入用户消息
  - 预期：消息正确处理，循环正确响应

- [ ] **场景 10：Sub Agent**
  - 创建 Sub Agent 并分配任务
  - 预期：Sub Agent 正确执行两阶段循环，总结回传给主 Agent

- [ ] **场景 11：前端展示**
  - 过程消息无复制按钮
  - 最终回复有复制按钮
  - 阶段切换指示器正常（如实现）
  - 流式输出无闪烁

- [ ] **场景 12：旧 Session 兼容**
  - 加载旧 Session（无 phase 字段）
  - 预期：正常加载，旧消息按 `Normal` phase 展示

- [ ] **场景 13：上下文压缩**
  - 在长对话中触发上下文压缩
  - 预期：压缩正常工作，不影响两阶段循环

- [ ] **场景 14：审批流程**
  - 触发需要审批的工具调用
  - 预期：审批流程正常，批准后继续 Loop，拒绝后进入总结
