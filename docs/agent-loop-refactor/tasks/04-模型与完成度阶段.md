# 04 - 模型与完成度阶段迁移

## 目标

建立生产状态机驱动骨架，并只迁移模型请求、流式响应、Summary 完成度检查和 ForceFinal，保持工具、审批和压缩暂由兼容适配层承接。

## 范围

- `react/execute.rs`
- `react/phase.rs`
- 模型与完成度相关辅助

## 任务

1. 接入已验证的阶段所有权驱动骨架。
2. 实现 `NeedModel`、`WaitingModel`、`CheckingCompletion`、`ForceFinal`、`PendingFinish` 的模型侧迁移。
3. 保持流式消息 ID、过程输出、Summary 提升和用量事件顺序。
4. 引导消息中断模型/Summary 时正确保存或降级部分输出。
5. 给暂未迁移的工具、审批、压缩建立窄兼容边界，并注明任务 05/06 的删除点。
6. 每个子阶段独立提交和验证；本任务不得同时迁移工具与压缩内部逻辑。

## 不做

- 不改变 Summary 触发策略。
- 不实现终态 ingress。
- 不做机械文件拆分。

## 验收

- 模型与完成度阶段由 `ExecutionPhase` 权威表达。
- 相关旧活动字段已移除或被明确隔离在短期兼容层。
- 关键事件顺序和 Summary 行为测试通过。

## 验证

```bash
cargo fmt -- --check
cargo clippy -p tiangong-core --all-targets --tests --benches -- -D warnings
cargo test -p tiangong-core
cargo check --workspace
```
