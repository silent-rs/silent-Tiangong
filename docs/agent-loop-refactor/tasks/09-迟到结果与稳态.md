# 09 - 迟到结果、可观测性与稳态验证

## 目标

完成结构化并发收尾，基于真实路径决定是否需要意图代际，并为阶段迁移和终态交接增加可诊断能力。

## 范围

- `react/phase.rs` / `execute.rs`
- 模型、工具、压缩结果归一化
- 结构化日志和测试

## 任务

1. 列出所有可能脱离阶段所有权返回的异步通道，证明取消/join 后是否仍可能迟到。
2. 对每类迟到结果定义：状态迁移、协议闭合、审计、用量和消息处理规则。
3. 仅对无法由结构化所有权保证的通道引入 `intent_generation`；不做全局机械加字段。
4. 增加 from_phase/event/to_phase、预算、封口状态等结构化日志。
5. 增加迁移失败、不变量破坏和旧结果处置的诊断。
6. 运行压力测试：连续引导、并行工具、压缩中断、命令风暴、取消和关闭。
7. 验证最新用户消息锚点、唯一生命周期、唯一终态和事件顺序。

## 不做

- 不无条件忽略旧工具结果。
- 不把日志正文写入敏感数据。

## 验收

- `intent_generation` 有明确必要性和覆盖；若无必要，文档记录“不引入”的决策。
- 所有迟到路径有明确处置规则。
- 压力和关键行为测试稳定通过。
