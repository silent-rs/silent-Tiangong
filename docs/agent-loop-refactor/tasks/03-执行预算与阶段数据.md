# 03 - 执行预算与阶段数据归属

## 目标

在不改变主控制流的前提下统一执行预算，并把未来阶段需要持有的数据类型移动到正确模块，为分阶段迁移消除可见性和循环依赖问题。

## 范围

- `react/phase.rs`（新增）
- `react/execute.rs`
- `react/mod.rs`
- 必要的内部可见性调整

## 任务

1. 定义 `ExecutionBudget`、`ExecutionLimits`，将 `outer_iteration` 改为 `continuation_count`。
2. 保留 `request_round` 的日志序号语义，明确新意图重置范围。
3. 将 `ActiveLlm`、工具批次、审批阶段、运行工具记录等阶段数据类型移动到 `phase.rs` 或调整为明确的 `pub(super)`；禁止复制类型。
4. 定义 `ToolExecutionPhase` 和同时持有 pending + batch 的 `ApprovalPhase`。
5. 定义阶段不变量校验辅助和 Debug 输出，不记录敏感正文。
6. 保持现有 `execute_turn` 控制流不变，先让旧结构复用新预算和类型。

## 不做

- 不接入完整 `ExecutionPhase` 驱动。
- 不改变 Summary、工具或命令行为。

## 验收

- 不再出现 `outer_iteration`。
- 阶段数据类型归属可支持后续兄弟模块使用。
- `WaitingApproval` 的设计数据包含完整工具批次。
- 所有现有测试通过。
