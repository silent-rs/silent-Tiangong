# 06 - 压缩阶段与续接迁移

## 目标

把上下文压缩建模为单一 `Compressing` 阶段，并显式表达压缩完成后返回哪个业务阶段。

## 范围

- `react/phase.rs`
- `react/compression.rs`
- `react/execute.rs`

## 任务

1. 定义 `CompressionPhase` 与 `CompressionReturn`，完整表达 React 文本、工具批次、Summary、上下文超限重试等续接。
2. 迁移自动压缩、强制压缩和取消路径。
3. 压缩完成只能迁移到 `return_to` 允许的阶段，不通过散落回调修改多个字段。
4. 用户引导时取消压缩并进入新意图；显式取消发布正确取消事件。
5. 保护 `summary_up_to`、CompressedResume、系统提示重建和用量累计语义。
6. 删除 `active_compression: Option` 和旧压缩推进路径。

## 不做

- 不调整压缩阈值和摘要提示词。
- 不修改完成度策略。

## 验收

- 压缩活动只由 `Compressing` 阶段持有。
- 所有续接路径都有自动化测试。
- 迟到压缩结果不能应用到新阶段。
