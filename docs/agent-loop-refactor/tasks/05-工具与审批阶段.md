# 05 - 工具批次与审批阶段迁移

## 目标

把工具准备、并行执行、失败恢复、去重和审批迁移到阶段状态机，确保工具协议与副作用语义完整。

## 范围

- `react/execute.rs`
- `react/phase.rs`
- 工具与审批辅助

## 任务

1. 实现 `PreparingTools`、`WaitingTools`、`WaitingApproval`。
2. `WaitingTools` 持有任务集合、运行记录和完整批次，保证一一对应。
3. `WaitingApproval` 同时持有待审批工具和完整批次。
4. 迁移批准、拒绝、FullTrust 恢复、迟到审批语义。
5. 迁移工具参数失败、同批重复、历史去重、失败恢复提示。
6. 用户引导和显式 Cancel 分别按契约闭合工具协议。
7. 验证插件独立后台任务不因普通引导被取消。
8. 删除工具/审批相关兼容字段和旧推进路径。

## 不做

- 不迁移压缩内部逻辑。
- 不改变工具权限规则或插件工具实现。

## 验收

- 工具和审批真实状态只由阶段表达。
- 不存在 pending approval 与所属 batch 分离的状态。
- 工具中断、取消、失败和并行完成的协议测试通过。

## 验证

```bash
cargo fmt -- --check
cargo clippy -p tiangong-core --all-targets --tests --benches -- -D warnings
cargo test -p tiangong-core
cargo test -p tiangong-plugin-agent-team
```
