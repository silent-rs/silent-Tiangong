# 07 - 统一命令与 PendingFinish 收敛

## 目标

让所有命令经过同一处理器，完成 `PendingFinish` 阶段语义，删除旧 `NextStep`、`can_advance` 和剩余并列活动状态。

## 范围

- `react/execute.rs`
- `react/phase.rs`
- `react/command.rs`（可新增）

## 任务

1. 定义 `CommandEffect`，禁止命令处理器直接制造多源阶段状态。
2. 统一处理用户消息、工具注入、Cancel/Shutdown、配置、标题、用量、插件事件和审批。
3. `PendingFinish + InjectTool` 撤销暂定结果并重新分析。
4. Pending result 不冻结旧用量；提交时读取最新累计用量。
5. 按命令顺序处理连续输入，决定性取消/关闭优先形成终态。
6. 移除 `NextStep`、`can_advance`、旧 `AgentLoopState` 和全部并列活动 `Option`。
7. 断言 `PendingFinish` 没有主循环活动资源。

## 不做

- 不实现跨线程入口封口（任务 08）。
- 不改变 Summary 策略。

## 验收

- 当前阶段唯一由 `ExecutionPhase` 表达。
- 暂定完成不吞命令，工具注入会重新分析，最终用量权威。
- 连续命令顺序测试通过。

## 验证

```bash
cargo fmt -- --check
cargo clippy -p tiangong-core --all-targets --tests --benches -- -D warnings
cargo test -p tiangong-core
cargo check --workspace
```
