确认 0.10.0 已发布后的当前开发边界，并让 `PLAN.md`、`TODO.md`、异常修复任务清单和相关进度文档保持一致。

- `PLAN.md`
- `TODO.md`
- `docs/exception-fixes-0.10.1/README.md`
- `docs/exception-fixes-0.10.1/PROGRESS.md`
- 必要时补充已有阶段文档中的状态说明

## 依赖

- 前置任务：无
- 后续任务：02、03、04、05、06、07

- 明确记录 0.10.0 已发布。
- 将当前主线从发布准备切换为 0.10.1 发布后异常修复。

## 不做

- 不调整版本号。
- 不创建 0.10.1 发布分支。
- 不修复 Workspace Index。
- 不重构 ReAct 主循环。
