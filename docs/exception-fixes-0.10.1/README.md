# 0.10.1 当前异常修复任务清单

> 背景：0.10.0 已发布。当前阶段不继续扩展新功能，优先修复发布后暴露的 Agent 协作与运行时异常。
>
> 方法依据：`/Users/hubertshelley/Documents/ai/AI开发方案总结/AI协作复杂开发流程工程化方法.md`
>
> 当前目标版本建议：0.10.1

## 开发边界

### 本阶段要做

- 修复影响 AI 协作效率和可信度的当前异常。
- 先处理 P0/P1 稳定性问题，再处理结构化优化。
- 每个任务独立 spec、独立验证、独立提交。
- 修复过程中如果发现设计边界变化，先更新对应 spec，再改代码。

### 本阶段不做

- 不开发新的浏览器/终端/多 Agent 用户功能。
- 不扩大到 0.11.0 规划功能。
- 不重写 Memory、Index 或 ReAct 执行引擎。
- 不把文档同步、索引修复、工具调用修复和 ReAct 重构混在同一个提交。

## 优先级定义

| 优先级 | 含义 |
|---|---|
| P0 | 阻塞当前 AI 协作或导致开发边界混乱，必须优先修复 |
| P1 | 明显影响 Agent 执行稳定性或后续修复风险，需要尽快修复 |
| P2 | 结构化优化或增强，可在 P0/P1 完成后推进 |

## 验证总原则

- 文档任务必须保证 `PLAN.md`、`TODO.md`、本目录进度记录之间无阶段冲突。
- 代码任务至少运行相关 crate 的 `cargo fmt -- --check` 与 `cargo check --workspace`。
- 前端相关任务如涉及 UI 或 Tauri API，需运行 `yarn --cwd frontend build`。
- 如果验证因环境限制无法运行，必须在 `PROGRESS.md` 中记录原因和替代检查。
