# T017-T020 - 交互模型重做（request_user 非阻塞方案）

> 方案全文：`../interaction-model-redesign.md`（对 T014/T015 实现的重做）。

## 任务拆分

- T017 请求管理器与授权表（tiangong-core::interaction）：
  InteractionRegistry（create/respond/expire/cancel/close/query，原子闭合、
  绝对 deadline、轻量计时任务）、挑战表（arguments_hash 绑定）、
  授权表（Once/Runtime Grant，运行期内存、会话隔离）。
- T018 Core 执行模型改造：request_user 统一工具（六 kind、独占批次协议修复）、
  ToolBatchOutcome::DeferredToUser、删除 wait_approval/wait_interaction/
  Command::Approval/Command::Interaction/AgentInput 两变体/Session.approved_tools、
  Supervised 无授权返回 approval_required 挑战、授权校验与消费、
  Command::ResolveInteraction、start_user_turn 拆出
  start_turn_from_latest_session/resume_with_tool_result、新消息取消 Pending。
- T019 入口与 UI：resolve_interaction 命令、interaction.requested/closed 事件、
  前端卡片（六 kind + 倒计时 + 关闭禁用）、CLI 六 kind、
  respond_approval/respond_interaction 移除、agent-team 事件同步。
- T020 验收：方案十九的 20 个场景测试 + 文档同步。

## 关键决策

- InteractionRegistry 放 tiangong-core（依赖方向：plugin-runtime 依赖 core，
  registry 需被 core 与入口层共用）。
- 信任模式映射：FullTrust→审批策略 Never（直接执行）；Supervised→Always
  （无授权返回挑战）。
- 超时默认 15s（常量，可配置留后续）；审批超时不产生授权。
- 事件层新增 interaction.requested/closed；旧 ApprovalNeeded/InteractionNeeded
  移除（同分支内无兼容包袱）。
