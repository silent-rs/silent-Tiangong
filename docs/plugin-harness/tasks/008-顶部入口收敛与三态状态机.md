# T008 - 顶部入口收敛 + 拓展区三态状态机

## 目标

把顶部「终端」「浏览器」两个独立按钮收敛为单个「拓展区」按钮，并把拓展区升级为三态状态机（关闭态 / 矩阵态 / App 态）：矩阵态作为打开 App 的统一入口（含浏览器/终端官方入口，功能不回退），App 态顶部提供启动台按钮快速回到矩阵。

## 范围

- 前端：`StatusPanel.tsx`（入口收敛）、`MainApp.tsx`（三态状态机）、`TabsContainer.tsx`（启动台按钮 + 末 tab 关闭回矩阵）、新增 `ExtensionMatrix.tsx` 骨架（官方 App 卡片）。

## 依赖

- 前置任务：T007（App 元数据 API 已就绪，矩阵骨架预留接入）。
- 后续任务：T009（矩阵视图完整化：三方 App、已打开标识、运行态）、T010（singleton/multi 实例管理、三方 App tab 内容渲染）。
- 可并行任务：无。

## 任务

- [ ] StatusPanel：删除终端/浏览器两个按钮，替换单个「拓展区」按钮（网格图标）；激活态 = 存在任一已打开 tab；agent 使用中绿点 = 任一 App 被 agent 使用（browserAgentActive || terminalAgentActive 泛化）。
- [ ] MainApp：新增 `workspaceMode: 'app' | 'matrix'`；「拓展区」按钮 toggle——面板开则收起，关则按规则进入（有已打开 tab → 上次 App 态；无 → 矩阵态）；`openWorkspacePanel(kind)` 保持并置 App 态；新增 `showExtensionMatrix()`。
- [ ] TabsContainer：tab 栏最左侧固定启动台按钮（点击回矩阵态）；最后一个 tab 关闭时回到矩阵态（不再直接收起面板）。
- [ ] `ExtensionMatrix` 骨架：网格展示官方内置 App（浏览器/终端）卡片，点击进入对应 App 态；预留三方 App 数据接入位（T009）。

## 不做

- 三方 App 卡片与已打开/数量/运行态标识（T009 矩阵视图）。
- 三方 App 的 tab 实例管理与内容渲染（T010）。
- 会话隔离机制改动（沿用现有 browser/terminal 按 session 路由）。

## 验收

- 顶部只有一个「拓展区」按钮；无 tab 时点击进入矩阵态，可从矩阵打开浏览器/终端（等价原两个按钮的能力）。
- 有 tab 时点击聚焦 App 态；App 态点启动台回矩阵态；关闭最后一个 tab 回矩阵态而非收起面板。
- agent 使用浏览器/终端时「拓展区」按钮显示使用中绿点；任一 tab 打开时按钮高亮。
- 原有行为不回退：agent 经 `browser:open` 强制弹面板、窗口拖窄自动收起、会话切换实例隔离。

## 验证

- `yarn --cwd frontend build`、`yarn --cwd frontend test` 通过。
- 新增状态机单测（矩阵/App 切换、末 tab 回矩阵、按钮 toggle）。
- 手动冒烟：收敛按钮打开矩阵 → 打开终端/浏览器 → 启动台往返 → 关闭全部 tab 回矩阵。
