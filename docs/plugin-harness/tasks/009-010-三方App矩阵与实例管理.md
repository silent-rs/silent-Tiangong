# T009/T010 - App 矩阵接入三方 App 与实例管理

> 与 T008（三态状态机 + 矩阵骨架）合并实施，本文为补录 spec。

## 目标

- T009：矩阵视图接入三方 App（`extension.tab` 贡献经 `listExtensionApps` 列出），与官方 App 同一启动台网格。
- T010：三方 App 实例可打开——`open_mode: singleton` 聚焦已有实例、`multi` 每次新建；实例以 plugin tab 形态进入拓展区 tab 栏，经标准沙箱容器（shadow/iframe）渲染内容，关闭/持久化/会话恢复与内置 App 一致。

## 实施内容（2026-08-17，提交 `97eb63ca`）

- 后端布局层：`WorkspaceTabKind` 增加 `Plugin`；`TabState` 增加可选 `plugin_id`/`contribution_id`/`sandbox`；布局文件新增 `plugin_tabs` 持有三方实例元数据，`get_session_tabs` 并入混排恢复。
- 前端：`TabKind` 扩展 `'plugin'`；`AppTabCommand` 增加 `open-plugin` 动作（携带 App 元数据），单例聚焦/多例新建；plugin tab 关闭无后端运行时调用；内容经 `PluginAppTabContent` 取入口 HTML 挂 `PluginSandbox`，挂载保活。
- `ExtensionMatrix`：`listExtensionApps` 加载三方卡片（拼图图标 + 贡献标题），点击/右键打开；图标名到 lucide 的映射留待 T016 SDK/UI Kit。

## 验收

- v2 插件声明 `extension.tab` 后出现在矩阵；singleton 重复打开聚焦同一 tab，multi 每次新建；关闭后回矩阵；会话切换实例隔离恢复。
- 布局层 `plugin_tabs` 元数据往返测试；前端全部测试通过。

## 遗留

- 三方 App 卡片的「已打开」绿点与实例数量徽标：需 MainApp 感知 plugin 实例集合（`onTabKindsChanged` 扩展），随首个真实三方插件冒烟时补。
- 三方 App 右键菜单暂仅「打开」（关闭全部/聚焦依赖实例感知，同上）。
- 真实三方 App 的 GUI 冒烟待 v2 插件制品（T016 示例插件一并验证）。
