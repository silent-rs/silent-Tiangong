# Memory 主数据库可读性与迁移恢复需求

## 已确认范围

本次以 PR #521 Review 报告为准：记忆属于用户数据，主数据库改为普通、无加密的 SQLite，不再为新库设置自动生成的密码。旧的版本化加密要求由本需求替代。

## 验收要求

- 新库可用普通 SQLite 工具直接打开；迁移后不再依赖用户主目录或存储目录派生的密码。
- 自动兼容历史用户主目录密钥（含 Windows 路径变体）及 #521 存储目录 v2 密钥。
- 在副本上导出和检查，核对所有表的内容与数量，包含记忆正文及关联关系；转换前完成 WAL 检查点，保留原加密库备份。
- 转换期间进程退出后，启动不能创建空数据库：新流程保留原库直至原子替换；兼容 #521 原库已移走的状态，从备份自动恢复。备份损坏或密钥不匹配时明确失败并保留数据。
- 原生索引不可用时，Windows 路径以及反斜杠、百分号、下划线按字面搜索；列表和计数一致。
- LanceDB 向量搜索逻辑及数据目录不变；不包含终端沙箱、应用启动或额外版本升级。
- 在 Windows 执行编译及既有检查，并使用真实数据库备份的隔离副本验证转换和普通 SQLite 读取，不替换用户正在使用的数据库。
