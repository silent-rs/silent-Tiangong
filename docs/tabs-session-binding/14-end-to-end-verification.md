# 14 - 端到端验收

## 目标

验证统一工作区 Tabs 的关键路径，确保后端、前端和 Agent 命令执行策略闭环可用。

## 验证清单

- 新会话点击终端按钮，出现终端 Tab。
- 新会话点击浏览器按钮，出现浏览器 Tab。
- 同一会话新增多个终端 Tab，cwd 和输出互不覆盖。
- 同一会话新增多个浏览器 Tab，URL 和标题互不覆盖。
- 浏览器 `about:blank` 首次导航正常。
- Tab 栏能混排浏览器和终端。
- 切换会话后恢复对应 Tab 集合。
- `run_command` 复用空闲终端。
- 所有终端繁忙时，`run_command` 新建终端执行。
- 新建终端执行时，工具结果告知 Agent 使用了新终端。
- `terminal_send` 写入当前选中的可用终端。

## 必跑命令

- `cargo fmt -- --check`
- `cargo check --workspace`
- `yarn build`

## 不做

- 不新增功能。
- 不做大范围重构。
- 只允许修复验收发现的小问题。

## 验收

- 必跑命令全部通过。
- 验证清单全部通过或记录明确的阻塞原因。
