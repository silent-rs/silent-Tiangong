# 08 - 前端单一工作区面板

## 目标

主布局从浏览器/终端两个面板状态收敛为一个工作区面板状态。

## 范围

- `frontend/src/pages/MainApp.tsx`
- `frontend/src/components/StatusPanel.tsx`

## 依赖

- 前置任务：无。
- 后续任务：09、10、11、12。
- 可并行任务：02、03、04、06。
- 阻塞说明：该任务只收敛前端面板外壳，不依赖后端运行时能力；后续统一 Tabs 容器会接入具体能力。

## 任务

- 用 `showWorkspacePanel` 替代 `showBrowser` / `showTerminal`。
- 浏览器按钮和终端按钮都打开同一个工作区面板。
- 面板未打开时，按钮点击决定首个 Tab 类型。
- 面板已打开时，按钮点击新增对应类型 Tab。
- 关闭面板时隐藏浏览器 WebView。
- 保留原窗口扩展、拖拽宽度、低宽关闭逻辑。

## 不做

- 不实现 TabsContainer 细节。
- 不改终端后端。
- 不改浏览器后端。

## 验收

- 点击浏览器按钮打开工作区面板。
- 点击终端按钮打开同一个工作区面板。
- 面板打开后再次点击按钮不会打开第二个面板。
- 拖拽和关闭行为保持可用。

## 验证

- `yarn build`
